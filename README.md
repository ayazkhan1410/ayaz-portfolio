# Ayaz Khan — Developer Portfolio

A single-file developer portfolio: **one `index.html`, plain HTML, CSS and JavaScript**, with no framework, no build step and no dependencies apart from Google Fonts.

**Live:** https://ayazkhan1410.github.io/ayaz-portfolio/

## Features
- The page "builds itself" on load: agent cursors assemble each section, and you can skip the build.
- A giant outlined **PORTFOLIO** wordmark hero, with a live `django · runserver` log panel.
- Dark and light themes, following the system setting, with a toggle.
- Experience timeline, a flagship project with an interactive claim pipeline, project cards and a skills grid.
- A built-in **Code** view that shows the page's own source.

## Make it yours
1. **Fork** this repo, or download `index.html`.
2. Open `index.html` and change the text: your name, role, experience, projects, skills and contact links. All the content is in the HTML. Colours are CSS variables at the top (`--red`, `--bg` and so on).
3. Publish it for free with **GitHub Pages**: go to *Settings → Pages → Build and deployment*, set *Source: Deploy from a branch*, choose `main` and `/ (root)`, and save. Your site goes live at `https://<your-username>.github.io/<repo-name>/`.
